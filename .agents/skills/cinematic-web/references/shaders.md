# GLSL / Shaders

Shader concepts:

Vertex shader
- changes geometry position

Fragment shader
- controls pixel/color output

UV coordinates
- map textures to geometry

Uniforms
- pass time, mouse, scroll progress and other values

Varyings
- transfer values from vertex to fragment shader

Common effects:
- noise
- displacement
- waves
- image distortion
- liquid
- RGB separation
- mouse distortion
- scroll distortion

For performance, keep shader complexity appropriate for the target device.
