# /public/videos

Drop your real .mp4 exports here using the filenames already referenced in
`src/data/projects.ts` (e.g. `real-estate.mp4`, `saas.mp4`, `embassy.mp4`,
`taj-hotel.mp4`, `harrdy-sandhu.mp4`, `bennett-night.mp4`,
`before-raw.mp4`, `after-final.mp4`).

Keep exports web-optimized (H.264, moderate bitrate, no audio track needed
since every project video is rendered muted) — this keeps the lazy-loading
video system fast.
